# 三子棋（井字棋）双人对战游戏
## 一、项目介绍
### 项目概述
本项目基于 **C++17 + FTXUI终端图形库** 开发一款控制台双人三子棋小游戏，严格采用C++工程规范：**头文件(.hpp)与源文件(.cpp)分离**，模块化拆分游戏逻辑与界面代码，告别单文件堆砌代码，符合C++面向对象课程作业规范。
游戏实现双人轮流落子、胜负自动判定、平局判定、一键重置对局等完整功能，界面由FTXUI组件搭建，落子后下方文本实时刷新X/O棋子标记，直观区分双方落点。

### 技术栈
- 编程语言：C++17
- UI框架：FTXUI
- 构建工具：CMake

### 仓库文件目录
项目文件夹/
├── main.cpp        // 程序入口、界面渲染、按钮交互逻辑
├── game.hpp        // 游戏函数声明头文件
├── game.cpp        // 棋盘、胜负规则功能实现
├── CMakeLists.txt  // CMake编译配置脚本
├── .gitignore      // 忽略编译缓存、临时文件配置
└── README.md       // 项目说明文档
> FTXUI第三方库不存入代码仓库，需使用者本地额外配置。

## 二、使用说明
### 1. 环境准备
1. 提前下载完整FTXUI源码文件夹，文件夹命名固定为 `FTXUI`；
2. 将`FTXUI`文件夹与**本项目文件夹放在同一个父目录（同级并列）**。
父目录/
├── MyFTXUIGame(项目文件夹)
└── FTXUI(第三方库文件夹)

### 2. 编译&运行
1. 使用Visual Studio打开项目文件夹，编译配置选择 `x64-Debug`；
2. VS自动解析CMake配置，等待依赖加载完成，点击【生成】构建可执行程序；
3. 生成完毕后启动程序即可开始游戏。

### 3. 游戏玩法
1. **X先手、O后手**，点击棋盘空白方框完成落子；
2. 横/竖/斜向三颗棋子连成一线，对应玩家直接获胜；
3. 棋盘填满无连成线棋子，系统判定平局；
4. 随时点击【重新开局】按钮清空棋盘，开启新对局；
5. 界面下方文本实时展示全棋盘`[X]/[O]`点位，方便查看落子。

## 三、贡献指南
### 1. 代码编写规范
1. 语法标准：统一使用C++17，头文件后缀`.hpp`，实现文件后缀`.cpp`；
2. 工程规范：新增功能必须遵循「头文件声明、源文件实现」分离原则，禁止所有代码写入main.cpp；
3. 格式规范：代码缩进使用4空格，变量、函数命名语义化，关键逻辑添加注释。

### 2. 提交与PR规范
1. 开发流程：先Fork仓库 → 新建功能分支 → 在分支内开发修改，**禁止直接在main主分支提交代码**；
2. Commit提交注释格式：`【改动类型】修改内容`，示例：`【优化】优化棋盘渲染逻辑`、`【修复】修正平局判定漏洞`；
3. 开发完成后提交Pull Request，维护者审核代码无误后合并至主干。

### 3. 可选拓展开发方向
1. 新增人机对战AI（电脑自动落子）；
2. 拓展为五子棋、四子连线玩法；
3. 新增胜负弹窗、计分统计功能；
4. 优化界面布局，美化棋子样式。

## 四、补充说明
本项目仓库**不含FTXUI源码**，因第三方库体积过大，统一由使用者本地自行部署。
