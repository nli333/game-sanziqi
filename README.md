# game-sanziqi
# 三子棋双人对战小游戏
## 项目简介
本项目采用C++17 + FTXUI终端UI库开发双人井字棋游戏，代码遵循模块化规范，**头文件与源文件分离编写**，结构清晰，满足课程作业要求。

## 游戏规则
1. X玩家先手落子，X、O双方轮流点击空位下棋；
2. 横、竖、斜线三个相同棋子连成一线即对应玩家获胜；
3. 棋盘填满无胜者判定平局；
4. 点击【重新开局】按钮一键重置对局。

## 文件结构
- game.hpp：棋盘操作、胜负判定函数声明（头文件）
- game.cpp：棋盘初始化、落子、输赢逻辑代码实现
- main.cpp：程序入口、FTXUI界面布局、按钮交互逻辑
- CMakeLists：项目编译配置文件
- .gitignore：过滤编译缓存、VS生成的临时文件

## 编译运行说明
1. 本项目依赖FTXUI第三方库，**不存入代码仓库**；
2. 将FTXUI源码文件夹和项目文件夹放在同一级目录；
3. 使用Visual Studio打开项目文件夹，选用x64-Debug配置；
4. CMake自动加载依赖，生成后直接运行即可游玩。

## 界面说明
界面上方为可点击操作的棋盘按钮，下方实时渲染棋盘文字`[X]/[O]`，落子后即时刷新标记，直观查看落子位置。
